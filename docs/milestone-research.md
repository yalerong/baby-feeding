# 里程碑功能调研与实现依据

调研日期：2026-10-14。对象：家中足月、目前7个月的宝宝。入口沿用已有小程序的「生长」页。

## 已核实的现有做法

以下依据官方公开页面和功能介绍，未登录付费产品、实测其完整流程或验证推荐算法及育儿效果。

| 产品 | 官方公开的做法 | 本项目采用的部分 |
| --- | --- | --- |
| [CDC Milestone Tracker](https://www.cdc.gov/act-early/milestones-app/) | 按月龄查看清单；提供照片、视频、活动建议，以及可与医生沟通的摘要；支持早产矫正月龄 | 使用可追溯的清单、观察提示和沟通摘要；当前宝宝足月，直接按首页生日计算月龄 |
| [Pathways.org Baby Milestones](https://pathways.org/mobile-app) | 根据年龄与里程碑提供日常推荐，结合能力记录、示例视频和亲子活动 | 把记录与可执行的陪玩建议关联，帮助家长知道下一步如何观察 |
| [Kinedu Assessment](https://www.kinedu.com/assessment) | 问题随年龄调整，提供已观察到、尚未、不确定等回答；家长观察用于后续技能与活动匹配；也提供自有发育模型报告 | 保留「不确定」选项，以日常可见行为提问；匹配活动时说明依据 |

本项目不具备 Kinedu 自有模型的数据和校准依据，因此不计算发育年龄、能力百分位或智能水平。上述产品的功能介绍不能作为本项目改善发育效果的证据。

## 选用的清单与月龄口径

- 原始项目来自 [CDC 6个月清单](https://www.cdc.gov/act-early/digital-online-checklist/6-months.html)（12项）、[9个月清单](https://www.cdc.gov/act-early/digital-online-checklist/9-months.html)（13项）和 [12个月清单](https://www.cdc.gov/act-early/digital-online-checklist/1-year.html)（10项），按社交情绪、语言交流、认知探索、动作发展分组，中文自行整理。
- CDC 指导：年龄介于两个清单节点时，使用较低月龄的清单。因此7至8个月默认回顾6个月节点，满9个月和12个月切到相应节点。后续阶段可预览，标明无需提前完成。
- 当前版本覆盖6、9、12个月；低于6个月或满15个月后，明确显示预览/历史参考，不提供当前月龄的活动匹配。
- 清单用于家庭观察与专业沟通，不替代标准化发育筛查。当前参考月龄出现「还没观察到」、技能退步或其他担忧时，应与儿保医生沟通，不能用陪玩建议延后评估。

## 第一版落地方式

1. 每项提供观察提示；回答保留「已观察到 / 还没观察到 / 不确定」。未填写单独显示「未记录」，不当成不会。
2. 「还没观察到」表示已有自然观察机会但尚未见到；「不确定」适用于记不清、没有机会观察或无法判断。避免根据聊天描述自动替家长勾选。
3. 观察日期记录这次观察，不标成首次达成日期。每项保存最新结果和可选备注，以家庭码共享；同项并发修改以后保存的内容为准。
4. 从 CDC [6个月活动建议](https://www.cdc.gov/act-early/milestones/6-months.html)、[9个月活动建议](https://www.cdc.gov/act-early/milestones/9-months.html)和 [12个月活动建议](https://www.cdc.gov/act-early/milestones/1-year.html)整理小量陪玩卡片。仅在宝宝处于6至14个月且查看当前参考节点时匹配，优先提供尚待观察项目的活动；这是可解释的规则匹配，不是临床评估或 AI 诊断。
5. 可复制当前清单摘要（包括未记录项、观察日期、备注和来源），由家长自行分享给医生或家人；应用不主动发送。
6. 复用原有生日、家庭码、云函数及配色，不新增底部标签和外部服务，不引入新的依赖类型。

## 取舍与后续范围

当前先完成「观察 → 记录 → 对应活动 → 再观察」的基本流程。先不做付费课程、视频素材采集、全月龄清单、自动视频判定、照片上传和大模型接口。活动参与反馈与长期观察历史可在实际使用后单独设计；第一版的活动匹配只依据月龄和已保存的观察状态，不分析备注内容，也不声称已理解宝宝的性格或接受能力。

## 验收

- 7个月默认6个月清单，9和12个月清单显式预览；满9个月和12个月切换相应参考节点。
- 35个项目有稳定标识；未填写保持未记录，记录数量不作能力评分。
- 保存失败保留草稿；重复提交不产生重复文档；同家庭重新进入可读取，不同家庭互不覆盖。
- 陪玩卡片匹配所选当前节点及记录状态，下一阶段预览不推送提前练习；摘要真实保留未记录和不确定状态。
- 运行项目完整测试及微信 WXML/WXSS 编译；云端部署与真机验证单独注明。
